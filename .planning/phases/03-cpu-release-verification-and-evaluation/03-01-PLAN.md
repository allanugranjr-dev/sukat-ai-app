<task type="auto">
  <name>Add read-only evaluation module</name>
  <files>ai-service/app/evaluation/__init__.py, ai-service/app/evaluation/reference.py, ai-service/app/evaluation/report.py</files>
  <action>
    Create `app/evaluation/reference.py`:
    - `EvaluationReference` dataclass: key, value_cm (finite, 5..300), source (default "tape"), consented: bool = True.
    - `parse_references(mapping) -> list[EvaluationReference]`: accept a dict key->cm or a list of records; ignore invalid rows (return only valid, consented rows). Never raise on a malformed reference; drop it.

    Create `app/evaluation/report.py`:
    - `MeasurementError` dataclass: key, provider_cm (float|None), reference_cm, delta_cm (float|None), error_cm (float|None), error_pct (float|None).
    - `evaluate_result(result, references) -> EvaluationReport`:
      - `EvaluationReport`: internal_evaluation: True, measurement_errors: list[MeasurementError], matched_count, referenced_count, note describing that no reference/accuracy is fabricated.
      - Match provider measurements by key with a small alias table (chest_circumference|chest, waist_circumference|waist, hip_circumference|hip, thigh_left_circumference|thigh, upper_arm, shoulder, inseam, height).
      - For a reference with a matching provider value in cm: delta = provider - reference, error_cm = |delta|, error_pct = error_cm/reference*100 (skip if reference <= 0).
      - For a reference with NO provider match: emit a MeasurementError with provider_cm=None, delta/error/error_pct=None (excluded, not fabricated).
      - The function is pure: it never mutates `result` and never writes anywhere. It only reads measurement values.
  </action>
  <verify>
    <automated>ai-service\.venv\Scripts\python.exe -m pytest -q ai-service/tests/test_evaluation.py 2>&1 | tail -5</automated>
    <automated>grep -q "internal_evaluation" ai-service/app/evaluation/report.py && echo "eval flag present"</automated>
  </verify>
  <done>
    app/evaluation contains pure parse + report modules; reports are tagged internal_evaluation and never fabricate accuracy for unmatched references.
  </done>
</task>
