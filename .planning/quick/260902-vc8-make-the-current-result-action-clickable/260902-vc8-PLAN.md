# Quick Task: Make the current result action clickable

## Goal

Make the customer result action usable when the displayed scan is already shared, without resetting persisted scan state or changing dressmaker access rules.

## Task 1: Make the shared result action explicitly repeatable

- **Files:** `src/App.tsx`
- **Action:** Keep new `ready_to_share` results on the manual “Send to dressmaker for review” path, but allow already shared `ready_for_review` and `verified` results to use a clear “Send again to dressmaker” action. Treat the repeat action as idempotent so it does not attempt an invalid lifecycle transition.
- **Verify:** Run the frontend typecheck, automated tests, and production build; confirm the action no longer receives the `reviewSent` disabled condition and that shared statuses remain dressmaker-visible.
- **Done when:** The current screenshot’s button is clickable, the label accurately describes the repeat action, and no existing customer, backend, storage, or role boundary is weakened.

## Must-haves

- Fresh processed results still require an explicit customer click before sharing.
- Existing shared records remain shared and are not reset in the database.
- `verified` records do not attempt a forbidden downgrade to `ready_for_review`.
- The action remains disabled only while busy or when no measurements exist.
